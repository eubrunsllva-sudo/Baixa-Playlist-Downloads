# Guia de instalação

## Requisitos

- Windows 10 ou Windows 11 de 64 bits.
- Acesso à internet para baixar conteúdo.

Python, Node.js e FFmpeg não precisam ser instalados separadamente no computador que vai usar o aplicativo.

## Instalar

1. Acesse a página [Releases do Baixa Playlist](https://github.com/eubrunsllva-sudo/Baixa-Playlist/releases).
2. Abra a versão mais recente e baixe `Baixa-Playlist-Instalador-1.0.1.exe` (ou o instalador da versão mais recente).
3. Abra o arquivo baixado e siga as instruções do Windows.
4. Inicie **Baixa Playlist** pelo atalho da Área de Trabalho ou pelo Menu Iniciar.

A instalação é feita somente para a conta atual do Windows. Não é necessário copiar a pasta `release` nem outros arquivos do projeto.

## Aviso do Windows

Como o instalador não tem assinatura digital, o Windows pode exibir um aviso de aplicativo não reconhecido. Só continue se baixou o instalador da página oficial de Releases deste projeto e conferiu o nome do arquivo.

## Atualizar

Baixe e execute o instalador da versão mais recente. Se o instalador avisar que o aplicativo está aberto, feche o Baixa Playlist e escolha **Repetir**.

## Solução de problemas

- **O download não inicia:** abra a seção **Atividade** e leia a mensagem de erro. Confira se o link é válido, se a pasta de destino permite gravação e se a conexão está ativa.
- **Conteúdo exige conta:** use a opção Firefox somente se o conteúdo estiver disponível para a sua conta e você tiver autorização para salvá-lo. Feche o Firefox antes da tentativa. Não compartilhe seus cookies.
- **“Ferramentas de download não foram encontradas”:** instale a versão atual a partir de Releases. O instalador oficial inclui as ferramentas necessárias.
- **O Windows bloqueou o instalador:** confira se o arquivo veio da página de Releases deste repositório. Não execute cópias recebidas de terceiros.
